# 常见问题 FAQ

## 🖥️ 支持的操作系统

**Q：密语 CipherTalk 支持 macOS 或 Linux 吗？**

A：目前密语 CipherTalk 仅支持 **Windows 10/11**。macOS 和 Linux 版本暂未提供。

---

## ❓ 关于其他工具的咨询

**Q：如何在 macOS 上安装 AstrBot？**

A：AstrBot 是一个独立的开源 AI 机器人框架，与本项目（密语 CipherTalk）**无关**。

如需了解 AstrBot 的安装和使用方法，请参阅其官方仓库和文档：

- **GitHub**: [https://github.com/Soulter/AstrBot](https://github.com/Soulter/AstrBot)
- **官方文档**: 请查阅 AstrBot 仓库内的 README 或 Wiki 以获取 macOS 安装指引。

> 本仓库仅维护 CipherTalk 相关内容，无法解答与本项目无关的工具安装问题。
